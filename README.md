# 42 Curriculum

At Codam Coding College I have followed the curriculum designed by the 42 Network. It's a project based curriculum starting you off with the C language to learn the fundamentals of programming.  
There is also multiple C++ projects that introduce you to OOP and a web development project.  
|Link|Description|Languages/technologies|
|------|------|-|
|[Codam_projects](https://github.com/jmolenaa/Codam_projects/blob/main/README.md)|A repository containing all 42 projects|C, C++, Docker, bash, Javascript|
|[cub3d](https://github.com/tknibbe/cub3d)|Graphical project about making a raycaster engine, similar to Wolfenstein.|C|
|[webserv](https://github.com/jmolenaa/webserv)|A basic webserver build in C++. Based on nginx with basic functionality.|C++|
|[ft_transcendence](https://github.com/akrepkov/transcendence)|WORK IN PROGRESS. A website on which you can play pong. Will support account creation, match history, tournaments and the game itself.|HTML, CSS, Javascript, Typescript|
|[minishell](https://github.com/bantunesfranco/minishell)|A basic shell with limited functionality based on bash. Pipes, environment variables, redirections, some builtins.|C, bash|

# Advent of code

Advent of code is a coding challenge happening once a year in December. The goal is to solve a programming puzzle in a language of your choice every day for 25 days.
